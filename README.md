# J.A.R.V.I.S. — Just A Rather Very Intelligent System

**Claude Code сам собирает себе штат под ваш бизнес.** Вы не ставите программы руками и не разбираетесь в скиллах. Вы вставляете три промпта, отвечаете на несколько вопросов о себе — и получаете личную систему с правилами, памятью и «отделами», которые работают на вашу задачу.

Сделано в [IKIGAI PROMOTION](https://ikigaipromotion.kz) для интенсива по вайб-кодингу. Работает на Windows и macOS.

## Три волны

| Волна | Где | Что происходит | Время |
|---|---|---|---|
| 1. Окружение | агент Cursor | ставит Git, Node.js, PowerShell 7, FFmpeg и сам Claude Code | 5–15 мин |
| 2. Ядро + знакомство | Claude Code в терминале Cursor | «Просыпайся, JARVIS» — 9 сотрудников ядра; затем `/jarvis:setup` — интервью, правила, память, разбор ваших файлов, доктор, оргструктура | 20–35 мин |
| 3. Отделы | там же, когда нужно | `/jarvis:hire` — маркетинг, продажи, дизайн, аналитика, Google, Higgsfield, сервер 24/7… только под вашу задачу | по запросу |

Промпты — в папке [`prompts/`](prompts/):
- `01-okruzhenie-windows.md` / `01-okruzhenie-mac.md`
- `02-prosypaysya-jarvis.md`
- `03-znakomstvo.md`

## Что в ядре (одинаково для всех)

| Сотрудник | Что делает |
|---|---|
| jarvis | сборка, доктор, найм отделов, ревизия, оргструктура |
| superpowers | методики: план → действие → проверка |
| context7 | свежая документация любых сервисов |
| exa | поиск и ресёрч в интернете |
| frontend-design | страницы и интерфейсы без шаблонного вида |
| skill-creator | собирает новых «сотрудников» под ваши задачи |
| claude-md-management | следит за правилами CLAUDE.md |
| document-skills | Word, Excel, PowerPoint, PDF |
| ceo-council | совет из пяти AI-директоров для решений |

Ядро добавляет в каждую сессию около 2 300 токенов из окна в 1 000 000. Отделы ставятся только под задачу: лишние сотрудники путают агента.

## Команды JARVIS

| Команда | Что делает |
|---|---|
| `/jarvis:setup` | знакомство и сборка под вас |
| `/jarvis:doctor` | проверка всех слоёв, таблица |
| `/jarvis:hire` | нанять отдел под задачу |
| `/jarvis:review` | ревизия штата: кто работает, кто простаивает |
| `/jarvis:orgchart` | показать оргструктуру |

## Запасной путь установки ядра

Если Claude Code отказался ставить плагины сам, вставьте одну строку в терминал.

Windows (PowerShell):
```
irm https://raw.githubusercontent.com/ikigai-promotion-kz/jarvis/main/install-core.ps1 | iex
```

macOS:
```
curl -fsSL https://raw.githubusercontent.com/ikigai-promotion-kz/jarvis/main/install-core.sh | bash
```

## Что нужно до начала
- Подписка Claude Pro, Max, Ultra, Team или Enterprise. Бесплатный план Claude Code не включает.
- Установленный Cursor и открытая в нём рабочая папка (не Рабочий стол и не домашняя).
