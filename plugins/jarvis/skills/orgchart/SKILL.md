# Оргструктура JARVIS

1. Если в рабочей папке нет `jarvis-orgchart.html` — скопируй туда `${CLAUDE_SKILL_DIR}/template.html` под этим именем.
2. Собери данные:
   - хозяин, бизнес, клиенты, главная задача — из `./CLAUDE.md` и памяти;
   - что реально установлено — `claude plugin list` и папки `~/.claude/skills/`.
3. Перепиши в файле **только** блок между `/*DATA*/` и `/*END*/`. Формат объекта `JARVIS` оставь как в шаблоне. Статусы отделов:
   - `on` — установлен и проверен;
   - `later` — подходит задаче, можно нанять через `/jarvis:hire`;
   - `off` — не нужен сейчас.
4. В поле `for_you` пиши, что отдел делает **для этого хозяина**, одной строкой, без общих слов.
5. Отделы, которые рисуешь как `on`, сверь с выводом команд. Нарисовать «на месте» то, чего нет, — главная ошибка.
6. Открой страницу: Windows — `start jarvis-orgchart.html`, Mac — `open jarvis-orgchart.html`.
