# Доктор JARVIS

Проверяешь систему и честно показываешь, что на месте. Зелёный отчёт без доказательства — не приёмка: каждую строку подтверждай выводом команды или содержимым файла.

## Запреты
- Ничего не удаляй и не переустанавливай.
- Существующие CLAUDE.md, MEMORY.md, `.env` не перезаписывай.
- Отделы сверх ядра сам не доставляй — только спрашивай.
- Не выдумывай: не смог проверить — пиши «не проверено» и почему.

## Проверки (по порядку)

| № | Слой | Как проверить |
|---|---|---|
| 0 | Рабочая папка | `pwd` / `Get-Location`. Домашняя папка, Рабочий стол или корень диска — красный флаг |
| 1 | Окружение | `git --version`, `node --version`, `npm --version`, `ffmpeg -version` (первая строка), на Windows `pwsh --version` |
| 2 | Claude Code | `claude --version`; если есть, `claude doctor` — показать итог |
| 3 | Ядро | `claude plugin list`: superpowers, context7, exa, frontend-design, skill-creator, claude-md-management, document-skills; папка `~/.claude/skills/ceo-council/SKILL.md` |
| 4 | Правила | `~/.claude/CLAUDE.md` и `./CLAUDE.md` — есть ли, сколько строк, первые 5 строк |
| 5 | Память | `~/.claude/projects/<проект>/memory/MEMORY.md` — есть ли, сколько записей |
| 6 | Отделы | папки в `~/.claude/skills/` и плагины сверх ядра — перечислить |
| 6а | Ключи | `.env` есть; `.env` в `.gitignore`; сколько ключей заполнено — только число, значения не показывать |
| 7 | MCP | `claude mcp list` — какие серверы подключены и отвечают |
| 8 | Вес штата | `claude plugin details <имя>` по каждому плагину — строка «Always-on» (токены в каждой сессии); число скиллов сверх ядра. Больше 30 — предупредить: лишние сотрудники путают агента, предложить `/jarvis:review` |

## Что можно чинить самому
- Нет плагина ядра — поставь командой из `${CLAUDE_SKILL_DIR}/../hire/catalog.md` (раздел «Ядро»), повтори проверку.
- Нет `./CLAUDE.md` — предложи запустить `/jarvis:setup`.
- Нет папки `inbox/` — создай пустую.
- Нет `.env` или `.gitignore` — создай из шаблонов `${CLAUDE_SKILL_DIR}/../setup/env.template` и `gitignore.template`.

## Что только сообщить
- Нет Git, Node или FFmpeg. Повтори промпт волны 1 в агенте Cursor.
- Нет Claude Code или `claude` «не найден». Закрой Cursor полностью (Windows — крестик и проверить, что не висит в трее; Mac — ⌘ + Q) и открой заново: новые программы видны только после перезапуска.
- MCP не отвечает. Перезапусти Claude Code; не помогло — запиши в отчёт.

## Финал
Одна строка: «JARVIS готов к работе» или «JARVIS готов на N из 8 слоёв, осталось: …».
Если что-то ставил — напомни перезапуск: `Ctrl + C` дважды, затем `claude`.
