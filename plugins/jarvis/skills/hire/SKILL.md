# Найм отдела

Подбираешь хозяину «сотрудников» под его задачу. Правило: нанимай под задачу, а не впрок. Описание каждого скилла сидит в контексте каждой сессии, поэтому лишние сотрудники замедляют и путают.

Каталог — `${CLAUDE_SKILL_DIR}/catalog.md`. Ставь только оттуда. Нужного нет в каталоге — не ищи наугад в интернете, предложи собрать свой скилл через `skill-creator`.

## Шаги
1. **Задача.** Спроси, какую работу хозяин хочет поручить новому отделу. Нужна одна конкретная задача, а не «маркетинг вообще». Перед вопросом прочитай `./CLAUDE.md` и память — возможно, ответ уже есть.
2. **Подбор.** Предложи 1 отдел и в нём 2–5 сотрудников. По каждому:
   - имя как в каталоге;
   - что сделает именно для этой задачи;
   - нужен ли ключ или вход.
   Отдельной строкой — что брать не советуешь и почему.
3. **Согласие.** Жди «да». Без согласия не ставь.
4. **Установка.** Выполни команду из каталога. Сначала одной строкой скажи, откуда ставится код (репозиторий) и что он делает. Если система безопасности отказала («Untrusted Code Integration» или похожее) — не обходи. Покажи хозяину, что внутри скилла (первые строки SKILL.md из репозитория), и попроси разрешить.
5. **Проверка.**
   - Скилл: папка `~/.claude/skills/<имя>/SKILL.md` есть.
   - Плагин: он виден в `claude plugin list`.
   - Не появилось — повтори команду один раз. Снова нет — запиши «не встало» и остановись.
6. **Отдел с ключом (волна 3).** Ключ хозяин вписывает сам в `.env` рабочей папки (строка уже приготовлена). В чат ключ не просить и не выводить. Для подключения прочитай значение из `.env` в переменную и подставь в команду так, чтобы оно не попало в вывод (например, PowerShell: `$k = (Get-Content .env | Select-String '^FIRECRAWL_API_KEY=').ToString().Split('=',2)[1]`). Ключа в `.env` нет — подскажи, где его взять (ссылка в комментарии файла).
7. **Оргструктура.** Если в рабочей папке есть `jarvis-orgchart.html` — обнови в нём блок `/*DATA*/`: отдел «на месте», дата.
8. **Финал.**
   - Напомни перезапуск: `Ctrl + C` дважды, затем `claude`.
   - Предложи первую задачу для нового отдела — ту, ради которой нанимали.
   - Если сторонних скиллов стало больше 30 — предложи `/jarvis:review`.
