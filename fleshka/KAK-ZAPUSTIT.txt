J.A.R.V.I.S. · ФЛЕШКА НА СЛУЧАЙ ПЛОХОГО ИНТЕРНЕТА (только Windows 10/11, 64 бит)

1. Вставить флешку в ноутбук участника.
2. Открыть флешку → папка JARVIS-INSTALL → правой кнопкой по PODGOTOVKA.cmd → «Запуск от имени администратора» → «Да».
3. Через 1–3 минуты окно скажет «ФЛЕШКУ МОЖНО ВЫНУТЬ» — вынуть и идти к следующему ноутбуку.
4. Через 10–20 минут окно покажет таблицу из 8 строк. Все «да» — готово. Есть «НЕТ» — запустить ещё раз
   (установленное пропустится) или попросить агента Cursor починить по журналу.

Что ставится: Cursor, Git, Node.js, PowerShell 7, Python, FFmpeg, Claude Code, расширение Claude Code в Cursor.
Создаются папки Документы\Cursor и Документы\Claude\inbox. Пак остаётся в Документы\Cursor\JARVIS-PAK.
Подключения к серверу нет — свой сервер каждый решает сам, позже.
Mac с флешки не ставится — на Mac волна 1 идёт из интернета по странице seriya-1.
