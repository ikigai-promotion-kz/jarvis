# Волна 2 · Знакомство — JARVIS собирает себя под вас

**Где:** тот же терминал, после перезапуска Claude Code.
**Сколько:** 15–25 минут. Отвечаете на 5–7 вопросов, JARVIS пишет правила, память, разбирает INBOX и показывает свою оргструктуру.

**До начала:** положите в папку `INBOX` рабочей папки 3–5 файлов о бизнесе — прайс, презентацию, описание услуг, отзывы. Можно скриншоты.

---

Наберите:

```
/jarvis:setup
```

JARVIS сам задаст вопросы по одному. Отвечайте как живому помощнику — коротко, своими словами.

---

**Что получится:**
- `CLAUDE.md` в рабочей папке — правила работы с вами и вашим бизнесом;
- `~/.claude/CLAUDE.md` — язык, тон и запреты для всех папок;
- первые записи в долговременной памяти;
- `BIZNES.md` — выжимка из ваших файлов, со ссылками на источники;
- таблица доктора;
- страница `jarvis-orgchart.html` — оргструктура вашего JARVIS, откроется в браузере.

**Дальше:** перезапуск (`Ctrl + C` дважды, затем `claude`) и первая задача: «JARVIS, начинаем — …».

**Нанять отдел позже** (маркетинг, продажи, аналитика, дизайн…): `/jarvis:hire`.
