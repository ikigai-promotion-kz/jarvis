Подготовь этот компьютер к работе с Claude Code. Я не программист — объясняй каждый шаг простыми словами, по-русски, коротко.

Установку делает готовый скрипт: он ставит программы из пака JARVIS-PAK (я скачал его с Google Диска), а чего в паке нет — из интернета официальными командами. Уже установленное он пропускает и ничего не удаляет. Твоя работа: запустить скрипт, показать мне итог и починить то, что не встало.

1. Пак. Найди папку JARVIS-PAK (или JARVIS-PAK-Windows) — сначала в этой рабочей папке, потом в «Документах», потом в «Загрузках» (Downloads). Нет папки, но есть архив JARVIS-PAK-Windows.zip — скрипт распакует его сам. Нет ни папки, ни архива — скажи мне одной строкой: «Пак не найден, ставлю из интернета, это дольше», и продолжай.

2. Свежий скрипт. Скачай его с GitHub в папку пака (или в рабочую папку, если пака нет). Команда для PowerShell:
   Invoke-WebRequest https://raw.githubusercontent.com/ikigai-promotion-kz/jarvis/main/install-windows.ps1 -OutFile install-windows.ps1
   Не скачался (нет интернета, ошибка) — возьми копию install-windows.ps1, которая уже лежит в паке.

3. Запуск. Перед запуском скажи мне две вещи:
   - сейчас Windows спросит «Разрешить этому приложению вносить изменения?» — нужно нажать «Да»;
   - откроется второе синее окно и будет молчать 5–15 минут, его не закрывать.
   Затем выполни в PowerShell из папки со скриптом:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\install-windows.ps1
   Если пак лежит не там, где ищет скрипт, добавь в конец: -Pak "<полный путь к папке пака>"

4. Итог. Скрипт печатает таблицу из 8 строк: Git, Node.js, npm, PowerShell 7, Python, FFmpeg, Claude Code, расширение Claude Code в Cursor. Покажи её мне.

5. Если есть строки «НЕТ» — почини именно их, по одной:
   - сначала запусти скрипт ещё раз (уже установленное он пропустит);
   - не помогло — поставь эту программу сам: из пака, а если её там нет — через winget с флагами --accept-source-agreements --accept-package-agreements. Перед каждой установкой коротко скажи, что ставишь и зачем;
   - «не найдена» сразу после установки — это нормально: открытое окно ещё не видит новые программы. Проверь заново после перезапуска Cursor, PATH сам не правь;
   - нет winget и программы нет в паке — остановись и скажи мне: нужно поставить «Установщик приложений» (App Installer) из Microsoft Store.
   Журнал установки — файл jarvis-ustanovka-log.txt в папке пака. Если непонятно, что пошло не так, прочитай его.

6. Расширение Claude Code. Если в таблице оно «НЕТ» и починить не вышло — скажи мне: я поставлю сам через Extensions (Ctrl + Shift + X) → поиск «Claude Code» → издатель Anthropic → Install.

7. В конце одной строкой: всё ли готово к запуску Claude Code. Отдельной строкой напомни мне закрыть Cursor полностью (все окна, крестиком) и открыть заново — до перезапуска новые программы не подхватятся.
