Подготовь этот компьютер к работе с Claude Code. Я не программист — объясняй каждый шаг простыми словами, по-русски.

1. Сначала покажи, что уже стоит. Выполни по очереди: git --version, node --version, npm --version, pwsh --version, ffmpeg -version (мне нужна только первая строка), winget --version, claude --version. Выведи таблицу: программа | установлено (да/нет) | версия.

2. Ничего не переустанавливай, если программа уже стоит. Node.js нужен версии 20 или новее.

3. Чего не хватает — поставь через winget, всегда с флагами --accept-source-agreements --accept-package-agreements, по одной программе за раз:
   Git.Git (Git), OpenJS.NodeJS.LTS (Node.js и npm), Microsoft.PowerShell (PowerShell 7), Gyan.FFmpeg (работа с видео и аудио).
   Перед каждой установкой коротко скажи, что ставишь и зачем.

4. Если нет Claude Code (команда claude не найдена) — поставь его официальной командой из документации Anthropic, в PowerShell:
   irm https://claude.ai/install.ps1 | iex
   Перед этим открой страницу https://code.claude.com/docs/ru/setup и сверься: если команда там другая — используй ту, что в документации.

5. Если команды winget нет вообще — остановись и скажи мне: нужно поставить «Установщик приложений» (App Installer) из Microsoft Store.

6. После установки проверь версии заново и покажи итоговую таблицу. Если программа «не найдена» сразу после установки — это нормально: открытое окно ещё не видит новые программы. Не правь PATH сам, просто отметь это.

7. В конце одной строкой: всё ли готово к запуску Claude Code. Отдельной строкой напомни мне закрыть Cursor полностью и открыть заново — до перезапуска новые программы не подхватятся.

8. Поставь в Cursor расширение Claude Code — через него Claude Code запускается из меню, а не командой. Выполни: cursor --install-extension anthropic.claude-code
   Если команда cursor не найдена или установка не прошла — скажи мне: я поставлю сам через Extensions (Ctrl + Shift + X) → поиск «Claude Code» → издатель Anthropic → Install.
