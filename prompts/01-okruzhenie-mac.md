# Волна 1 · Окружение · macOS

**Где вставлять:** в чат агента Cursor (`⌘ + L`), не в терминал. Рабочая папка уже открыта в Cursor.
**Сколько ждать:** 5–20 минут.
**Что делаете вы:**
- На Mac установщики просят пароль от компьютера. Вводите его вы, агент только ведёт.
- Когда появится системное окно «Установить инструменты разработчика», нажмите «Установить».

```
Подготовь этот Mac к работе с Claude Code. Я не программист — объясняй простыми словами, по-русски, по одному шагу за сообщение.

1. Сначала покажи, что уже стоит. Выполни по очереди: git --version, node --version, npm --version, brew --version, ffmpeg -version (только первая строка), claude --version. Выведи таблицу: программа | установлено (да/нет) | версия. Если brew «не найден», попробуй полный путь /opt/homebrew/bin/brew (Apple Silicon) или /usr/local/bin/brew (Intel).

2. Ничего не переустанавливай, если программа уже стоит. Node.js нужен версии 20 или новее.

3. Нет Git — выполни xcode-select --install и предупреди меня, что появится системное окно с кнопкой «Установить».

4. Нет Node.js — сам не ставь, проведи меня: открыть nodejs.org, кнопка LTS, скачанный файл .pkg из «Загрузок», «Продолжить», «Установить», пароль от Mac. Если Homebrew уже есть — вместо этого предложи brew install node.

5. FFmpeg ставим, только если есть Homebrew: brew install ffmpeg. Homebrew нет — пропусти FFmpeg и скажи, что он понадобится только для видео и его можно поставить позже.

6. Нет Claude Code (claude не найден) — поставь официальной командой: curl -fsSL https://claude.ai/install.sh | bash
   Перед этим открой https://code.claude.com/docs/ru/setup и сверься: если команда другая — используй ту, что в документации. Если установщик попросит добавить строку в ~/.zshrc для PATH — сделай это и скажи мне.

7. После установки проверь версии заново и покажи итоговую таблицу. В конце одной строкой: всё ли готово к запуску Claude Code. Отдельной строкой напомни закрыть Cursor полностью через ⌘ + Q и открыть заново.
```

**Как понять, что всё получилось:** после перезапуска Cursor откройте терминал (`Control + ``` — клавиша слева от единицы, или View → Terminal), наберите `claude --version` — должна появиться версия. Затем — волна 2.
