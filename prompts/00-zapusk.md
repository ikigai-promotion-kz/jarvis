# Короткие промпты запуска

Длинные промпты лежат в файлах .txt: в чате и терминале длинный текст иногда обрезается, файл — нет. Два действия: скачайте файл (он попадёт в «Загрузки», там его и оставьте) и вставьте короткий промпт. Путь к файлу писать не нужно: агент сам найдёт файл и положит в inbox.

## Волна 1 · в чат агента Cursor (папка Cursor открыта)
Файл: 01-okruzhenie-windows.txt или 01-okruzhenie-mac.txt

Windows:
```
Найди файл 01-okruzhenie-windows.txt: сначала в папке inbox этой рабочей папки, если там нет — в папке «Загрузки» (Downloads) моего компьютера. Нашёл в «Загрузках» — перенеси его в inbox. Прочитай файл и выполни задание из него по шагам. Последняя строка файла — «КОНЕЦ ЗАДАНИЯ». Если её нет, файл повреждён: скажи мне и ничего не делай.
```

Mac:
```
Найди файл 01-okruzhenie-mac.txt: сначала в папке inbox этой рабочей папки, если там нет — в папке «Загрузки» (Downloads) моего компьютера. Нашёл в «Загрузках» — перенеси его в inbox. Прочитай файл и выполни задание из него по шагам. Последняя строка файла — «КОНЕЦ ЗАДАНИЯ». Если её нет, файл повреждён: скажи мне и ничего не делай.
```
