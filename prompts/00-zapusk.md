# Короткие промпты запуска

Длинные промпты лежат в файлах .txt: в чате и терминале длинный текст иногда обрезается, файл — нет. Скачайте файл, переложите в папку inbox и вставьте короткий промпт, заменив путь на свой.

Как скопировать путь к файлу: Windows — Shift + правый клик по файлу → «Копировать как путь»; Mac — правый клик с зажатой Option → «Скопировать путь до …».

## Волна 1 · в чат агента Cursor (папка Cursor открыта)
Файл: 01-okruzhenie-windows.txt или 01-okruzhenie-mac.txt → в папку Cursor\inbox

```
Прочитай файл <путь>\Cursor\inbox\01-okruzhenie-windows.txt и выполни задание из него по шагам. Последняя строка файла — «КОНЕЦ ЗАДАНИЯ». Если её нет, файл повреждён: скажи мне и ничего не делай.
```
